# Gotchas — 공식 문서대로 했는데 안 되는 것

실제 호출에서 확인한 함정만 적는다. 각 항목에 확인 날짜를 붙인다. 하네스가 자동으로 막는 항목은 🛡️ 표시.

## API

| 함정 | 증상 | 해결 | 확인 |
|---|---|---|---|
| 조회 경로 | 문서의 `GET /v2/video_generation/{task_id}` → 404 | `GET /v2/query/video_generation/{task_id}` 🛡️ | 2026-09-29 |
| 과금 | 출력 8초인데 16초 청구 | 참조 영상 길이도 과금된다(`usage.input_seconds`). `check`가 예상 초를 보여줌 🛡️ | 2026-09-29 |
| 모드 혼용 | first/last frame + reference_* 동시 사용 불가 | 둘 중 하나만 🛡️ | 2026-09-29 |
| 요청 크기 | base64로 넣으면 33% 커짐, 본문 64MB 제한 | 큰 파일은 공개 URL 또는 `mm_file://` 🛡️ | 2026-09-29 |
| 타임아웃 | 제출 중 네트워크 끊김 → 작업이 생겼는지 모름 | 원장이 `unknown`으로 남음. 바로 재제출하지 말고 콘솔에서 확인 🛡️ | — |

## 입력 파일

| 함정 | 증상 | 해결 | 확인 |
|---|---|---|---|
| 인스타 릴스 코덱 | 릴스는 VP9, H3는 H.264/H.265만 받음 | ffmpeg로 H.264 변환 🛡️ | 2026-09-29 |
| 릴스 다운로드 | `yt-dlp` 명령이 PATH에 없음 | `python3 -m yt_dlp <URL>` | 2026-09-29 |

## 프롬프트·참조

| 함정 | 증상 | 해결 |
|---|---|---|
| 카메라까지 따라옴 | 동작만 옮기려 했는데 원본 폰 촬영 거리·프레이밍이 그대로 | 영상은 "동작과 타이밍만", 프레이밍은 글로 지정 |
| 카메라 지시 충돌 | 카메라 레퍼런스가 있는데 글로 무빙을 또 씀 → 흔들림 | 컷별 프레이밍과 원본 타임스탬프만 적고 무빙 동사는 쓰지 않기 |
| 원본이 새어 들어옴 | 원본 배우·세트가 남음 | `Do not copy its actor/set/lighting` 명시, 안 되면 두 단계(피사체 교체 → 배경 교체) |
| 모양이 다른 피사체 | 사람 춤 → 네발 동물 등은 약함 | 덩어리 모양이 비슷한 레퍼런스 고르기 |
| 둥근 캐릭터의 팔 동작 | 짧은 팔 동작은 작게 뭉개짐. "팔을 뻗는다"를 쓰면 팔이 늘어남 | 큰 동작은 몸 전체(기울기·점프·회전)로 표현 |
| 부정어 역효과 | `no tail` 같은 부정 단어가 오히려 꼬리를 만듦 | 없는 것을 적지 말고 있는 것만 구체적으로 |

## 이미지 준비 (Codex CLI로 스틸 만들 때)

| 함정 | 해결 |
|---|---|
| 구버전 CLI는 최신 이미지 모델을 400으로 거부 | `npm i -g @openai/codex@latest` |
| `--image`가 뒤따르는 프롬프트까지 파일로 먹음 | 프롬프트는 stdin(`-`)으로 |
| 비대화형 셸에서 `codex`를 못 찾음 (nvm) | nvm bin 경로를 PATH에 추가 |
